# Reza Negahban

**Computational Biology & Bioinformatics**

My research interests include neoantigen prioritization, cancer immunology, computational biology, and reproducible scientific software.

## Featured Research Projects

### NeoRank-IR

Evidence-aware neoantigen prioritization research framework for computational immunology and personalized cancer-vaccine research.

**vNext-alpha research prototype.** Not clinically validated. The project is in private development; the source code is not publicly available.

### [Stem Cell Fate Explorer](https://github.com/rezang-1378/stemcell-fate-explorer)

Interactive exploration of human hematopoietic cell fate from public single-cell RNA-seq data using Scanpy, CellRank, GPCCA, and Streamlit.

[Explore the dashboard](https://stemcell-fate-explorer-ga7tintmqwwbt8rghe5dqb.streamlit.app/)

I aim to make scientific assumptions, data provenance, reproducibility limits, and interpretation boundaries explicit in my work.
